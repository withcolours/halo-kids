### 플래너 체크뷰 Phase A (2026-09-01~02, 배포·실기기 확인 완료)
planner-print를 인쇄 도구에서 **본 플래너의 태블릿 "종이 뷰"**로 전환. 데이터는 하나, 뷰는 기기별 (아이패드 가로 = 종이 뷰, 폰 = 시트 축소본, 폰 전용 "오늘" 뷰는 Phase B).

**데이터 모델** (스펙 planner-spec.md 모델의 부분집합 — Phase B에서 확장):
- `userPlanWeeks/{uid}/{주시작일}` = {memo, tasks[], savedAt} — **주별 스냅샷** (주중 조정은 그 주만, 과거 주는 체크 기록과 함께 영구 보존)
- `userPlanChecks/{uid}/{YYYY-MM-DD}/{taskId}` = timestamp
- `userPlanLibrary/{uid}` = 자주 쓰는 일정 배열
- task id는 문자열(`t`+base36) — Firebase 키 호환. 보안 규칙 3노드 추가·**콘솔 게시 완료(2026-09-02)**
- localStorage: `halokids_pp_cache_v1`(오프라인 캐시), `halokids_pp_migrated`(이관 플래그), `halokids_pp_panel`(패널 접힘). 레거시 `halokids_weekly_grid_v1`은 최초 로그인 시 1회 이관 안내

**UI/동작** (모두 사용자 승인 거침):
- 라이브 체크: 요약칸 줄 탭 = 완료 (노란 체크박스+취소선), 타임라인 블록에도 ✓·반투명. 출력물에도 반영
- 할 일 색상 = **옅고 얇은 페인트 스트로크**: 텍스트 길이만큼 글자 아래쪽 절반을 가늘게 지나는 붓칠. 불규칙 border-radius+미세 회전(nth-child 2n/3n 변주)+가로 그라디언트, 밴드 top 44%~bottom 20%, opacity .45(체크 시 .18). 결정 여정: 색 점(공간 차지)→네모 배경칠(답답)→형광펜 띠→페인트 느낌·더 옅게→두께 절반. 목업: https://claude.ai/code/artifact/2805d529-22ae-4729-9424-2a8fd819d4bb
- 주 이동 ◀▶/이번 주/날짜 선택. 빈 주 진입 시 3택: [지난주 복사(추천)/자주 쓰는 일정에서/빈 주로 시작]
- **[이번 주 삭제]**: 주 노드+그 주 체크를 통째로 삭제 → 3택 화면으로 복귀 (재복제 가능). 자주 쓰는 일정·다른 주 유지
- 오늘 컬럼 파란 테두리+「오늘」 배지. 우상단 "{닉네임} · 자동 저장됨" 동기화 표시, 실패 시 오류 코드 토스트
- **입력 패널 접기/열기** 토글(기기별 기억) — 뷰어 모드에서 시트가 전체 폭 사용
- 시트 축소 = **가로 꽉 채움** 기준(세로는 스크롤). 가로 넘침 근본 수정(`.landscape-grid` `minmax(0,1fr)`+`min-width:0`) 포함
- **iOS 저장**: PNG = 공유 시트(navigator.share 파일 공유 → 사진에 저장/파일/AirDrop), 실패 시 "길게 눌러 저장" 전체화면 오버레이 폴백. PDF는 팝업 불가 환경(홈 화면 앱)에서 동일 오버레이 폴백. 데스크톱은 기존 다운로드/인쇄 유지

**커밋 이력**: 0e551c9(본 구현+규칙) → dd37e9d(오류 코드 표시) → cd6dcf7(패널 접기) → c26052d(iOS 공유 저장) → 16c82b6(가로 꽉 채움) → 800398c(이번 주 삭제) → ee362c3(내보내기 PNG/PDF 드롭다운 + 크롬 크래시 수정)
