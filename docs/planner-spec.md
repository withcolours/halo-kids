## 핵심 컨셉
대문 = "오늘 할 일"(시간순 일과+할일, 파란 '지금' 마커). 주간 그리드(가로 월~일 × 세로 할 일)가 계획의 원본. 기존 메뉴판(책 6종/OTT)은 "고르기 계층"으로 흡수 + 메뉴판 카드에 [오늘 읽을래] 담기 버튼.

## 항목 모델
- **일과**(표시용, 체크 없음): 학교/학원/식사 등. 시간 필수. 오늘 타임라인+시간표 뷰에만.
- **할 일**(체크+별 대상): 지정형(특정 책) / 수량형("책 2권 읽기" → 체크 시 바텀시트로 책 할당, 카탈로그 검색+새 책 자유등록→userBooks) / 자유형(문제집 등). 시간 선택.
- **과제**: 마감일 있는 일회성(userTasks), 한 줄+날짜 밀어넣기, D-day 표시.
- 유형: 기본(책/영상/문제집·과제/운동/기타) + 사용자 커스텀.
- 반복 = days[0~6]. 그리드 편집 모드에서 셀 켜고 끄기 = 반복 설정. 행 길게: 복제/삭제/수정. [다음 주로 복사] = 일회성 포함.

## 화면 (7 + 내책장)
- ① 오늘(홈): 지금 마커, 불꽃 카드(7일 줄+보호권), ⭐잔고, 진행바, 과제 D-day, 할당 바텀시트, 하단 바로가기(책/영상/주간계획)
- ③ 주간 그리드(메인): 보기 전환 [✓할일 | 시간표(요일×시간축 컬러블록) | 원본이미지], 유형 필터(홈스쿨·과제만 = 홈스쿨 주간판, 행 끝 5/7), 상세보기 토글, 편집/다음주 복사, 주말 표시 토글
- ② 할 일 추가 ⑥ 과제 목록 ⑦ 보상 상점 ④ 부모 홈(아이 카드+승인 대기) ⑤ 프로필(생년 1970~, parent 역할, 아이 아이디 연결)
- ⑧ 내 책장: 읽은 책 표지 그리드(책장 뷰) + 월 달력에 날짜별 읽은 책 표지(달력 뷰). `readingLog/{uid}/{date}`가 평생 독서기록 원본, `userBooks/{uid}/{isbn}`에 서지 저장

## 계정 관계
- role: child|parent|admin. 생년이 성인(≈2007 이전)이면 parent 선택 가능
- `usernames/{username}=uid` 인덱스(가입 시 기록) → 부모가 아이 아이디 입력해 즉시 연결(`parents/{p}/children/{c}`)
- 부모: 연결 아이 계획 열람·수정, 통계. **체크는 아이만**. 계획 작성은 둘 다
